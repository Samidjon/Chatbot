ОБНОВЛЕНИЕ: DOIRA RHYTHM JOURNEY

Что добавлено
1. Новая страница game.html с обучающей ритмической игрой.
2. Игрок слушает рисунок и повторяет его ударами BUM (центр) и BAK (край).
3. 5 уровней, очки, ранги, факты о доире и управление клавишами B/K.
4. Коллекция из трёх доир: Classic, Emerald Heritage и Golden Master.
5. Прогресс, открытые доиры и выбранный дизайн сохраняются в аккаунте.
6. Переключатель языка EN/RU на странице игры.
7. Чат распознаёт просьбы вроде «Хочу поиграть в игру» и показывает кнопку перехода.
8. В шапке чата и среди быстрых вопросов добавлена ссылка на игру.

Как установить
1. Скопируйте все файлы из архива в корневую папку проекта.
2. Не удаляйте свой существующий файл daniel.png — он используется как аватар чат-бота.
3. Не заменяйте и не удаляйте свой существующий user.txt, если хотите сохранить аккаунты и историю.
4. Запустите проверку: npm run check
5. Запустите сервер: npm start
6. Откройте http://localhost:3000

Файлы game.html и game.js — новые.
Файлы index.html, script.js, style.css, server.js и package.json — дополнены без удаления основных функций чата и квиза.
